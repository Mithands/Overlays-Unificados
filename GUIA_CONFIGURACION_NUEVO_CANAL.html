INTEGRACIÓN

OBS Studio Navegador

1

Configurar el Nombre del Canal de Twitch

El primer paso es indicar a qué canal de Twitch debe escuchar el widget para procesar los mensajes del chat y sumar experiencia:

  1. Dirígete a la carpeta: Overlay-principal/Widget-chat/js/
  2. Si no existe el archivo config.js, copia config.example.js y renómbralo a config.js.
  3. Abre config.js con cualquier editor de texto o Bloc de Notas y modifica la línea del canal:
Overlay-principal/Widget-chat/js/config.js 
CHANNEL_NAME: 'nombre_del_nuevo_canal', // Escribe el usuario de Twitch en minúsculas
2

Crear la Base de Datos en la Nube (GitHub Gist)

Para que los niveles, la experiencia, los logros y las rachas se guarden solos mientras estás en stream de forma gratuita:

2.1 Crear el Gist (Tu Base de Datos)

  1. Inicia sesión en GitHub y entra en gist.github.com ↗.
  2. En Gist description escribe: Twitch Overlay XP Database.
  3. En Filename including extension escribe exactamente: xp_data.json.
  4. En el área de texto grande del archivo, copia y pega exactamente esta estructura inicial:
xp_data.json 
{
  "users": {},
  "metadata": {
    "version": "2.0.0",
    "created": "2026-09-02"
  }
}
  1. Abajo a la derecha, pulsa en "Create secret gist" (o "Create public gist").
  2. Copiar tu Gist ID: Mira la barra de direcciones de tu navegador. La URL tendrá un formato como este:
    https://gist.github.com/tu-usuario/7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d
    El código alfanumérico largo del final es tu GIST_ID. Guárdalo para el siguiente paso.

2.2 Crear el Token de Acceso (Tu Llave Secreta)

  1. En GitHub, haz clic en tu foto de perfil (arriba a la derecha) ➔ Settings (Configuración).
  2. En el menú lateral izquierdo, baja hasta el final y haz clic en Developer settings.
  3. Entra en Personal access tokens ➔ Tokens (classic).
  4. Haz clic en Generate new token ➔ Generate new token (classic).
  5. Rellena los campos:
    • Note: Twitch Overlay Token
    • Expiration: No expiration (o la duración que desees).
    • Select scopes: Marca únicamente la casilla gist (Create gists).
  6. Baja al final y pulsa el botón verde Generate token.
  7. Copia tu token generado (empieza por ghp_...).
IMPORTANTE: GitHub solo te muestra este token una vez. Guárdalo en un lugar seguro.
3

Pegar las Credenciales en config.js

Abre de nuevo el archivo Overlay-principal/Widget-chat/js/config.js y rellena los campos de la sección GIST_STORAGE:

Overlay-principal/Widget-chat/js/config.js 
// Gist Storage Config (Persistencia en la nube)
GIST_STORAGE: {
    ENABLED: true,
    GIST_ID: 'PEGA_AQUI_TU_GIST_ID',         // El código largo de la URL de tu Gist
    GITHUB_TOKEN: 'PEGA_AQUI_TU_TOKEN_GHP',   // Tu token personal ghp_...
    FILENAME: 'xp_data.json',
    SYNC_INTERVAL: 30000,
    AUTO_BACKUP: true
},

En la lista de EXCLUDED_TOP_USERS, asegúrate de poner tu propio nombre de canal para que no compitas contra tus espectadores en los tops:

Filtro de Exclusiones 
EXCLUDED_TOP_USERS: [
    'nombre_del_nuevo_canal', // Tu propio canal
    'streamlabs',
    'streamelements',
    'nightbot'
],
4

Añadir la Fuente en OBS Studio

  1. Abre OBS Studio.
  2. En tu escena de streaming, haz clic en el botón + en el panel de Fuentes.
  3. Selecciona la opción Navegador (Browser Source).
  4. Ponle de nombre Chat & XP Overlay.
  5. En la ventana de configuración:
    • ✅ Marca la casilla "Archivo local" (Local file).
    • Haz clic en Examinar y busca el archivo index.html (ubicado en Overlay-principal/Widget-chat/index.html).
    • Ancho (Width): 1920 (o 450 si solo usarás la columna del chat).
    • Alto (Height): 1080 (o 800 para solo chat).
    • ✅ Marca la casilla "Controlar audio a través de OBS".
  6. Pulsa en Aceptar.
5

Comprobación en Vivo y Comandos

Una vez iniciado tu stream o abriendo el archivo de pruebas Overlay-principal/Widget-chat/test-panel.html, puedes probar estos comandos interactivos en el chat:

COMANDO FUNCIÓN
!nivel o !nivel @user Muestra el nivel global, progreso de XP, racha activa y puesto en la Liga Mensual.
!topmes Muestra el podio oficial de la Liga Mensual del mes en curso (solo seguidores).
!top o !topxp Muestra el Top 3 de nivel y experiencia acumulada histórica.
!toplurk o !toptiempo Muestra el Top 3 de tiempo de visualización acumulado en streams.
!topracha Muestra el Top 3 de rachas activas de días seguidos participando.
!racha Consulta tus días consecutivos de racha y tu multiplicador actual (x1.0 a x3.0).
!ayuda Lista todos los comandos interactivos disponibles en el chat.
¡SISTEMA LISTO! Todos los puntos de experiencia, niveles, rachas y rankings se sincronizarán solos en la nube cada 30 segundos.
