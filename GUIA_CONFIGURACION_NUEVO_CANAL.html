Crear la Base de Datos en la Nube (GitHub Gist)

Para que los niveles, la experiencia, los logros y las rachas se guarden solos mientras estás en stream de forma gratuita y segura:

2.1 Crear el Gist (Tu Base de Datos)

  1. Inicia sesión en GitHub y entra en gist.github.com ↗.
  2. En Gist description escribe: Twitch Overlay XP Database.
  3. En Filename including extension escribe exactamente: xp_data.json.
  4. Copia y pega exactamente este JSON inicial:
xp_data.json 
{
  "users": {},
  "metadata": {
    "version": "2.0.0",
    "created": "2026-09-03"
  }
}
  1. Pulsa en "Create secret gist" (o "Create public gist").
  2. Copiar tu Gist ID: Mira la URL en la barra de direcciones de tu navegador:
    https://gist.github.com/tu-usuario/7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d
    El código alfanumérico largo del final es tu GIST_ID.

2.2 Crear el Token de Acceso (Tu Llave Secreta)

  1. En GitHub, haz clic en tu foto de perfil ➔ Settings (Configuración).
  2. En el menú lateral izquierdo, baja hasta el final y haz clic en Developer settings.
  3. Entra en Personal access tokens ➔ Tokens (classic).
  4. Haz clic en Generate new token ➔ Generate new token (classic).
  5. Rellena los campos:
    • Note: Twitch Overlay Token
    • Expiration: No expiration.
    • Select scopes: Marca únicamente la casilla gist (Create gists).
  6. Pulsa en Generate token y copia tu token generado (empieza por ghp_...).

2.3 Pegar Credenciales en config.js

Abre Overlay-principal/Widget-chat/js/config.js y completa la sección GIST_STORAGE:

Overlay-principal/Widget-chat/js/config.js 
// Gist Storage Config (Persistencia en la nube)
GIST_STORAGE: {
    ENABLED: true,
    GIST_ID: 'PEGA_AQUI_TU_GIST_ID',         // El código largo de la URL de tu Gist
    GITHUB_TOKEN: 'PEGA_AQUI_TU_TOKEN_GHP',   // Tu token personal ghp_...
    FILENAME: 'xp_data.json',
    SYNC_INTERVAL: 30000,
    AUTO_BACKUP: true
},

// Excluye a ti mismo y a tus bots de los podios de !top
EXCLUDED_TOP_USERS: [
    'tu_canal_aqui',
    'streamlabs',
    'streamelements',
    'nightbot'
],

Activar el Inicio Automático y Oculto del Servidor

Para no tener que iniciar el servidor manualmente cada vez que vayas a streamear y para que se ejecute de forma 100% invisible en segundo plano (sin ventanas de terminal abiertas):

  1. En la carpeta principal del proyecto, haz doble clic en Activar_Inicio_Automatico.bat.
  2. Este script configurará dos funciones de inmediato:
    • Inicia el servidor local en segundo plano en http://localhost:3000.
    • Instala un acceso directo invisible en el Inicio de Windows para que se levante solo al encender tu equipo.
¡LISTO Y AUTOMATIZADO! El servidor se ejecutará en silencio en el puerto 3000. Ya puedes abrir OBS directamente sin preocuparte por iniciar nada a mano.

(Nota: Si algún día deseas detenerlo o quitarlo del inicio, dispones de Detener_Servidor.bat y Desactivar_Inicio_Automatico.bat en la misma carpeta).

4

Configuración en OBS Studio (Lienzo y Panel Dock)

4.1 Añadir el Lienzo Unificado (Overlay en Escena)

No necesitas añadir 6 fuentes separadas; todo el stream se proyecta desde una única fuente coordinada:

  1. En OBS Studio, en tu Escena, pulsa en + en el panel de Fuentes.
  2. Elige Navegador (Browser Source) y nómbrala Lienzo Overlays Mithands.
  3. Configura los siguientes campos:
    • URL: http://localhost:3000/Overlay-principal/index.html
    • Ancho (Width): 1920
    • Alto (Height): 1080
    • ✅ Marca "Controlar audio a través de OBS" (para mezclar el sonido del TTS y alertas).
    • ✅ Marca "Actualizar el navegador cuando la escena se active".
  4. Pulsa en Aceptar.

4.2 Añadir el Master Control Dock (Panel Integrado)

Para controlar posiciones, visibilidad, metas, votaciones y sonido en directo sin salir de OBS:

  1. En el menú superior de OBS Studio, haz clic en Paneles (Docks) ➔ Paneles de navegador personalizados...
  2. En la ventana emergente, añade una fila:
    • Nombre del panel: Master Dock
    • URL: http://localhost:3000/Panel-control/master-dock.html
  3. Haz clic en Aplicar.
  4. Se abrirá el dock interactivo. Puedes arrastrarlo y anclarlo en cualquier lateral de OBS.

Comandos de Chat y Pruebas

Tu comunidad de Twitch puede interactuar inmediatamente mediante estos comandos:

COMANDO DESCRIPCIÓN
!nivel / !nivel @user Muestra la tarjeta de nivel cyberpunk, progreso de XP, racha activa y puesto en la Liga Mensual.
!topmes Muestra el podio oficial de la Liga Mensual del mes en curso (solo seguidores).
!top / !topxp Muestra el Top 3 de nivel y experiencia acumulada histórica.
!topracha Muestra los espectadores con mayor racha de directos seguidos.
!racha Consulta tus días consecutivos de racha y multiplicador activo.
!tts <texto> Lee el mensaje en voz alta en directo por el Bot TTS.
!ayuda Lista todos los comandos interactivos disponibles en el chat.
¡CONFIGURACIÓN COMPLETADA! El sistema sincronizará la experiencia en la nube cada 30 segundos y responderá en tiempo real a los controles del Master Dock.
